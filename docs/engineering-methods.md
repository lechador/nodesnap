## Sources and applicability

- Physical pool definitions and independent beam reference equations are explicitly derived in the [master specification](NodeSnap_Master_Build_Specification.md), E7 and E14. They are software fixtures, not proposed design members or approved pool designs.
- [Shapely manual](https://shapely.readthedocs.io/en/stable/manual.html): planar geometry/area operations; not a 3D structural solver.
- [OR-Tools CP-SAT](https://developers.google.com/optimization/cp/cp_solver) and [solver parameters](https://github.com/google/or-tools/blob/stable/ortools/sat/sat_parameters.proto): integer constraints and native solver outcome semantics.
- [PyNite member assumptions](https://pynite.readthedocs.io/en/latest/member.html), [analysis](https://pynite.readthedocs.io/en/latest/analysis.html) and [stability](https://pynite.readthedocs.io/en/latest/stability.html): API and solver applicability references.
- [ASHRAE indoor pools](https://handbook.ashrae.org/Handbooks/A23/SI/A23_Ch06/a23_ch06_si.aspx): registered research source, not a claimed licensed transcription of its empirical design method.
- The dated NYC profile and source links remain in Part D of the master specification and `packages/domain/src/domain/jurisdiction.py`. These profile references do not establish implemented compliance algorithms. Filing-date applicability, amendments and project facts require verification for real work.

## Reproducibility and statuses

Persisted analysis records include project/revision IDs, snapshot input hash, method version, source/exclusions, package versions, implementation hash, scenario ID and creation time. Old results with a different active revision or implementation hash are stale. Conservative invalidation covers all discipline groups after a mutation; detailed selective dependency reuse is not yet claimed.

Assumed inputs retain `demonstration_assumption`; derived values retain their explicit origins. Unsupported or unverified work cannot acquire `pass` from a successful solver/export. Villa result checks remain `not_evaluated`, professional review remains `unreviewed`, and authority process remains `not_submitted`.
