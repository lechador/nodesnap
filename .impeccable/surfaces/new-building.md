# New building

Mode: Operate. Code-led extension of the established architectural exhibition world; no replacement identity or approved image composition.

## THESIS
Turn the visitor's own building brief into a distinct saved architectural project. Show a fresh starting point, not a preselected villa that must be edited into something else.

## FIRST VIEWPORT
Charcoal studio navigation, a large direct question, one text/voice composer and three concrete starting briefs. A quiet empty drawing sheet anticipates the real model without fabricating a building before the brief is accepted. Saved buildings and the optional example remain easy to open. On mobile the composer leads and the empty sheet recedes.

## INTERACTION
Missing information becomes an inline clarification. Accepted creation opens the actual model and plans. Progress moves the drawing scan only while a request is active, and reduced-motion preferences disable it. Errors preserve the submitted brief for retry. Model geometry, project ownership and immutable history use the established controller.

## INHERITED SYSTEM
Use PRODUCT.md, DESIGN.md and .impeccable/design.json unchanged for visual tokens, typography, material direction and native focus/selection behavior. The feature introduces no external raster assets or new dependencies.
