# Homepage

Mode: Operate. Inherit the established architectural studio identity.
Scope: apps/web/app/components/StudioHome.tsx and the arrival navigation in apps/web/app/page.tsx.

## THESIS
A deliberate starting point for every visit. Choose a new house or a saved building before entering the architectural workspace. Never automatically open, create or upgrade a house on arrival.

## FIRST VIEWPORT
Charcoal wordmark header over an open ivory surface. A large, direct Geist headline anchors two distinct paths: a green “Build a new house” action and a complete saved-building list. A separately labeled example villa is available without becoming the default. No model, house illustration or fabricated project is shown. On mobile the sections stack, and every saved project remains reachable.

## INTERACTION
New house opens the text/voice brief. Selecting a saved project explicitly loads its current revision, including the existing guarded legacy upgrade when needed. New and returning sessions both arrive here on reload. Home controls return from the composer and workspace; keyboard focus follows the screen. Loading, connection retry and an honest empty-library state are visible. Busy requests and active recording prevent premature navigation.

## INHERITED SYSTEM
Use the existing Geist, charcoal, ivory and green tokens and shared controls. The paths settle upward once with exponential easing; reduced motion removes the transition. No external assets, new dependencies or deployment changes.
